# EggplantRecorder v0.1.0

## English

Record your screen from the menu bar. Files stay on your Mac.

### What you can do

- Record the **whole screen**, a **region**, a **window**, or part of a window
- Choose frame rate, resolution, countdown, microphone, and system sound before you start
- Pause or stop from a small on-screen bar (region and window recordings also show a dashed outline)
- After you stop: browse recordings, preview, rename, move to Trash, or trim and export
- Set save folder, language, and defaults in Preferences

The app lives in the menu bar — no big Dock window while you’re idle.

### Install

1. Download **EggplantRecorder-v0.1.0.dmg**
2. Open it and drag the app into **Applications**
3. If macOS says it can’t be opened, run once in Terminal:

   `xattr -cr /Applications/EggplantRecorder.app`

4. On first use, allow **Screen Recording**. Turn on the microphone in the app only if you also want mic audio (then allow **Microphone** when asked).

### Needs

- A Mac running **macOS 15** or later
- This build is signed for personal use and is **not** notarized by Apple

## 简体中文

从菜单栏录屏。文件都保存在你自己的 Mac 上。

### 能做什么

- 录制**整个屏幕**、**一块区域**、**某个窗口**，或窗口里的一部分
- 开始前可调帧率、分辨率、倒计时，以及麦克风和系统声音
- 录制中可用小控制条暂停或停止（区域 / 窗口模式还会显示虚线框）
- 停录后：浏览录像、预览、重命名、移到废纸篓，或裁剪后导出
- 在偏好设置里改保存位置、语言和默认选项

平时只待在菜单栏，不会占一个大大的 Dock 窗口。

### 安装

1. 下载 **EggplantRecorder-v0.1.0.dmg**
2. 打开后把应用拖进 **应用程序**
3. 如果系统提示无法打开，在终端执行一次：

   `xattr -cr /Applications/EggplantRecorder.app`

4. 第一次使用请允许**屏幕录制**。只有需要录麦克风时，再在应用里打开麦克风，并按提示允许**麦克风**权限。

### 运行环境

- 需要 **macOS 15** 或更新系统
- 当前为个人签名版本，**未经** Apple 公证
